# Documentation assets

The canonical documentation is text-first so implementation agents can work without AFFiNE access.

The six original Imperial Ledger PNG mockups are listed in [`../design-system.md`](../design-system.md). The current AFFiNE connector exposes their names and document references but not their binary contents, so this migration intentionally does not commit broken image links or fabricate replacements. When the original files are available, add them under `imperial-ledger/` using the stable filenames documented there.

Do not substitute franchise imagery, characters, Seikai symbols, Abh script, or third-party assets for the missing mockups.
