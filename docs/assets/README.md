# Documentation assets

The canonical documentation is text-first so implementation agents can work without AFFiNE access. The six original Imperial Ledger PNG mockups are stored under `imperial-ledger/` and embedded from [`../design-system.md`](../design-system.md).

Their stable filenames preserve the numbering from the source document:

1. `01-overview-desktop.png`
2. `02-services.png`
3. `03-service-details-ovh.png`
4. `04-providers-add-provider.png`
5. `05-overview-mobile.png`
6. `06-logo-wordmark-sheet.png`

The mockups are illustrative. Semantic tokens and behavioral requirements in the design-system document take precedence over pixel-level details.

Do not substitute franchise imagery, characters, Seikai symbols, Abh script, or third-party assets for the missing mockups.
